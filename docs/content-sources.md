## Editorial boundaries

Only public repositories are included. The external Farbrausch fork is not presented as original work. Older backups and duplicate simulation sources were omitted to keep the selection useful. The GitLab fan-control project whose README explicitly says it does not work is not featured as a functioning tool. Repository names and contents do not establish employment, education, professional credentials, or a project's release availability; no such claims were added.

Update this document and the visible content date when rechecking the sources. Keep status language consistent with each project's current README.
